# SiftRate Web App

React single-page application for [SiftRate](../README.md) — the personal media-life archive. It provides the search-and-rate experience, the personal library and the activity feed, and talks to the [API](../api/README.md) over REST with cookie-based sessions.

## Stack

| Concern       | Choice                                                 |
| ------------- | ------------------------------------------------------ |
| UI            | React 19 (with React Compiler)                         |
| Bundler / dev | Vite 8 + `@vitejs/plugin-react` and `vite-plugin-svgr` |
| Routing       | TanStack Router (file-based, automatic code-splitting) |
| Server state  | TanStack Query                                         |
| Client state  | Zustand                                                |
| HTTP          | `ky` with `credentials: 'include'`                     |
| Forms         | react-hook-form + Zod v4                               |
| UI primitives | `@base-ui/react` (shadcn-style)                        |
| Styling       | Tailwind CSS v4 + `tw-animate-css`, Geist font         |
| i18n          | intlayer (English, Ukrainian, Russian)                 |
| Icons         | `reicon-react`                                         |
| Lint / format | oxlint / oxfmt                                         |
| Tests         | Vitest                                                 |

## Requirements

- [Bun](https://bun.sh)
- A running SiftRate API (see [`api/README.md`](../api/README.md))

## Setup

```bash
# from the repository root
bun install

cp app/.env.example app/.env
cd app
bun run dev
```

The dev server runs at http://localhost:3000.

## Environment

Validated by [`src/common/constants/env.ts`](src/common/constants/env.ts) via `@t3-oss/env-core`. Only `VITE_`-prefixed variables reach the client bundle.

## Project structure

```
src/
  app/                 # application shell
    main.tsx           # entry point
    globals.css        # Tailwind + theme tokens + motion keyframes
    layout/            # Header, Layout, Navigation, Profile, Sidebar
    providers/         # Query, Router, Motion providers
    routes/            # TanStack file routes (+ generated routeTree.gen.ts)
  common/              # cross-feature code
    api/               # ky client and error helpers
    assets/ constants/ hooks/ schema/ types/ ui/ utils/
    theme/             # ThemeProvider
  modules/             # feature modules
    auth/ discover/ feed/ import/ library/ planned/
    profile/ ranked-list/ review/ settings/ user/
```

Feature code lives in `src/modules/<name>/` and is re-exported through each module's `index.ts` barrel. `~/` is aliased to `src/`.

## Routing

Routes are declared as files under `src/app/routes/`; the tree in `src/app/routeTree.gen.ts` is generated by the TanStack Router plugin and must not be edited by hand.

| Area             | Paths                                                                          |
| ---------------- | ------------------------------------------------------------------------------ |
| Auth             | `/auth`, `/auth/google/callback`                                               |
| Complete profile | `/complete-profile`                                                            |
| Home             | `/`                                                                            |
| Discover         | `/discover`, `/discover/{movie,tv_show,game,book,album,track}/$externalId`     |
| Library          | `/library`, `/library/reviews`, `/library/ranked-list`, `/library/planned`     |
| Settings         | `/settings`, `/settings/account`, `/settings/imports`, `/settings/danger-zone` |
| Profile          | `/$username`                                                                   |

The `/_app` layout holds the authenticated chrome and redirects users without a username to `/complete-profile`.

## Data layer

- HTTP client: [`src/common/api/api.ts`](src/common/api/api.ts) — a `ky` instance with `credentials: 'include'` that sends the current locale as `Accept-Language`.
- Errors are normalized by `getApiError` into `{ message, fieldErrors?, status? }`.
- Query defaults (`refetchOnWindowFocus: false`, `retry: false`, `staleTime: Infinity`) live in the TanStack Query provider.
- Browser storage goes through `getStorageItem` / `setStorageItem` with Zod validation.

## Internationalization

Configured in [`intlayer.config.ts`](intlayer.config.ts). Locales: English (default), Ukrainian, Russian, in `no-prefix` routing mode with the selection stored in `localStorage`.
